# v0.6.1 — A smoother start

The **Launch at login / 登录时启动** switch now remains usable on ad-hoc-signed community builds, where macOS may not expose the app as a ServiceManagement login item.

## Included

- Keeps macOS `SMAppService` for builds where the system login item is available.
- Falls back to a per-user LaunchAgent when macOS reports the app service as missing.
- Shows the actual registration error and keeps the switch interactive when system status is unavailable.
- Keeps login startup opt-in. The LaunchAgent starts the app at the next login.

## Download note

The attached ZIP is an **unsigned, unnotarized community preview**. It is ad-hoc signed for bundle integrity, but it is not Developer ID signed or notarized. macOS may block downloaded copies. Building from source with `./build.sh` is the recommended path until a Developer ID release is available.

The package targets macOS 13 or later and contains Intel and Apple silicon binaries. Runtime testing in this development checkout has been performed on Intel macOS 26. Other supported macOS releases and Apple silicon still need device testing. Windows is not supported.
