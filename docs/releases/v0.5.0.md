# v0.5.0 — Keep your next spark close

Codex Usage Bar brings the 5-hour and 7-day Codex plan windows into the macOS menu bar, adds a local idea garden for the pause, and celebrates only when a fresh response confirms both windows are available again.

## Included

- Universal macOS app bundle for Intel and Apple silicon.
- Live remaining-use indicator and reset countdown.
- Conservative dual-window recovery check and a manually dismissible reset reminder.
- Optional reset chime, 99 sourced bilingual thinking quotes, and local idea capture/library.
- Synthetic demo mode and verification scripts.

## Download note

The attached ZIP is an **unsigned, unnotarized community preview**. It is ad-hoc signed for bundle integrity, but it is not Developer ID signed or notarized. macOS may block downloaded copies. Building from source with `./build.sh` is the recommended path until a Developer ID release is available.

The package targets macOS 13 or later. Runtime testing in this development checkout has been performed on Intel macOS 26. Apple silicon and older supported macOS releases have build coverage but still need device testing. Windows is not supported by this release.

The included numbers and UI screenshots are synthetic previews. The app reads plan usage via the signed-in Codex CLI; API-key-only usage does not provide plan rate limits. A reset reminder can only be observed while the app is open and online.
