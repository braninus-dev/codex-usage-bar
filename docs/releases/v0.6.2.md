# v0.6.2 — Find the account you just switched to

Codex Usage Bar now follows account changes instead of holding on to the account its private app-server first loaded.

## Included

- Reconnects the app-server on the normal 60-second usage refresh, after sleep, and when you request a manual refresh. A fresh process reloads Codex's current credentials from either the file store or macOS Keychain.
- Reacts to app-server account and rate-limit update notifications.
- Watches only `auth.json` file metadata for a faster sync on file-backed logins. It never opens or reads credential contents.
- Replaces the displayed snapshot with the newly confirmed account's usage after a successful read. Account notifications and file-metadata changes clear the old snapshot while that sync is in progress.
- Keeps reset notices scoped to the account whose usage was observed.

## Download note

The attached ZIP is an **unsigned, unnotarized community preview**. It is ad-hoc signed for bundle integrity, but it is not Developer ID signed or notarized. macOS may block downloaded copies. Building from source with `./build.sh` is the recommended path until a Developer ID release is available.

The package targets macOS 13 or later and contains Intel and Apple silicon binaries. Runtime testing in this development checkout has been performed on Intel macOS 26. Other supported macOS releases and Apple silicon still need device testing. Windows is not supported.
